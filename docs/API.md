# API Reference

Base path: `/api`. All routes except `/api/auth/*` and `/api/health` require a valid
`clearflow_session` cookie (set after Google OAuth login) — see `app/core/security.py`.

## Auth

| Method | Path | Description |
|---|---|---|
| GET | `/api/auth/google/login` | Redirects to Google's OAuth consent screen. |
| GET | `/api/auth/google/callback` | OAuth callback; sets session cookie, redirects to `FRONTEND_URL`. |
| POST | `/api/auth/logout` | Purges session cookie (Complete Logout Protocol). |

## Onboarding

| Method | Path | Description |
|---|---|---|
| POST | `/api/onboarding/chitti` | Executes the full 4-step gated onboarding in one call. Creates 1 Chitti + S Shares, 0 Transactions. |

Request body:
```json
{
  "step1": { "chitti_name": "Gold Circle B", "rule_template": "Incremental Model V1" },
  "step2": { "total_members": 20, "total_months": 20, "monthly_commission": 4000, "undrawn_due": 5000, "drawn_due": 6000 },
  "step3": { "start_month_year": "2026-10", "cycle_anchor_day": "5th" },
  "step4": { "members": [{ "member_name": "Mahesh", "share_id": "CHAND1", "phone_number": "+919876543210" }, "... (S entries)"] }
}
```

## Chittis

| Method | Path | Description |
|---|---|---|
| GET | `/api/chittis` | List chittis owned by the authenticated manager. |
| GET | `/api/chittis/{chitti_id}` | Get one chitti. |
| GET | `/api/chittis/{chitti_id}/matrix` | Full deterministic M-month financial matrix. |
| POST | `/api/chittis/{chitti_id}/spawn-month` | Spawns exactly S transaction rows for `Current_Active_Month`. Idempotent — 409 if already spawned. |
| POST | `/api/chittis/{chitti_id}/advance-month` | Increments `Current_Active_Month`. |

## Shares

| Method | Path | Description |
|---|---|---|
| GET | `/api/shares/by-chitti/{chitti_id}` | Roster for the 5 sub-tab share cards. |
| POST | `/api/shares/payment` | Payment Drawer entry. Returns 409 with `requires_confirmation: true` if amount < due and `force_partial_confirm` wasn't set. |
| POST | `/api/shares/draw` | Inline Draw Winner Entry — sets `Draw_Status` / `Month_Drawn`. |
| PATCH | `/api/shares/contact` | Contact Editor — update member name/phone. |
| GET | `/api/shares/{share_id}/statement` | Builds the Personal Finance Statement payload (used by WhatsApp D+20 broadcast). |

## Dashboard

| Method | Path | Description |
|---|---|---|
| GET | `/api/dashboard/{chitti_id}/summary` | Page 2 ledger cards + Pocket Cash Indicator (surplus/deficit, green/red). |

## WhatsApp

| Method | Path | Description |
|---|---|---|
| POST | `/api/whatsapp/broadcast` | Sends pre-due / overdue / statement / custom messages via Chatwoot to `all_pending`, `all_shares`, or a specific `share_ids` list. |

## Google Drive

| Method | Path | Description |
|---|---|---|
| POST | `/api/drive/upload-receipt` | Uploads a receipt image directly to the manager's own Drive (`drive.file` scope); returns lightweight metadata only. |

## Health

| Method | Path | Description |
|---|---|---|
| GET | `/api/health` | Liveness check. |
